# Photo Report – Google Apps Script

โครงการนี้เป็น Google Apps Script สำหรับอัปโหลดรูปภาพจาก Sidebar แล้วบันทึกไฟล์ลงในโฟลเดอร์ Google Drive ที่กำหนด พร้อมแทรกรูปลงในเทมเพลตชีต `Photo_Report` โดยตรง รูปที่แทรกเป็นภาพแบบ **วางทับบนตาราง (Over-grid image)** จึงไม่ต้องเปิดไฟล์รูปเป็นสาธารณะเพื่อให้สูตร `IMAGE()` โหลดรูป โดย Google Sheets จำกัด Blob ที่ใช้แทรกภาพไว้ไม่เกิน 2 MB ต่อรูป [2].

## วิธีติดตั้ง

1. เปิดไฟล์ Google Sheet ที่มี Spreadsheet ID ข้างต้น และตรวจสอบว่ามีชีตชื่อ `Photo_Report` กับ `Asset_Master`.
2. เลือก **Extensions > Apps Script** เพื่อสร้างสคริปต์ที่ผูกกับไฟล์ชีตนั้นโดยตรง การผูกสคริปต์กับชีตมีความสำคัญ เพราะเมนูแบบกำหนดเองจะทำงานกับสคริปต์ที่ผูกกับไฟล์เท่านั้น [1].
3. เปิดไฟล์ `Code.gs` จากโครงการนี้ แล้วคัดลอกเนื้อหาทั้งหมดไปแทนที่ไฟล์ `Code.gs` ใน Apps Script.
4. สร้างไฟล์ HTML ใหม่ชื่อ `Sidebar` แล้วคัดลอกเนื้อหาจาก `Sidebar.html` ไปวาง.
5. กด **Save** จากนั้นเลือกฟังก์ชัน `checkPhotoReportSetup` แล้วกด **Run** หนึ่งครั้งเพื่ออนุญาตสิทธิ์การเข้าถึงชีตและโฟลเดอร์ Drive. ฟังก์ชันนี้ไม่แก้ไขข้อมูล จะคืนชื่อไฟล์ชีต ชื่อโฟลเดอร์ และสถานะการพบชีต.
6. กลับไปที่ Google Sheet แล้วรีเฟรชหน้าเว็บ หากเมนูยังไม่ปรากฏ ให้ปิดแล้วเปิดไฟล์ใหม่อีกครั้ง.
7. เลือกเมนู **ระบบจัดการรูปภาพ > เปิดหน้าต่างอัปโหลดรูป** จากนั้นเลือก Job ประเภทรูป และไฟล์รูปภาพ แล้วกด **อัปโหลดเข้าชีท**.

## โครงสร้างข้อมูลที่คาดหวังใน `Asset_Master`

สคริปต์ใช้ข้อมูลตั้งแต่แถวที่ 4 โดยอ่านค่า `Job No.` จากคอลัมน์ A และนำค่าคอลัมน์ D ถึง G มาต่อเป็นสถานที่ ดังนั้นโครงสร้างหลักควรเป็นดังนี้

| คอลัมน์ | ข้อมูล |
| --- | --- |
| A | Job No. เช่น `JOB-001` |
| D | อาคาร |
| E | ชั้น |
| F | แผนก |
| G | ห้อง |

หากข้อมูลเริ่มที่แถวอื่นหรืออยู่คนละคอลัมน์ ให้แก้ฟังก์ชัน `getJobData()` ใน `Code.gs`

## ทางเลือกของวิธีแทรกรูป

| วิธี | ข้อดีและข้อแลกเปลี่ยน | ค่าใช้จ่าย | ความซับซ้อนในการติดตั้ง |
| --- | --- | --- | --- |
| **แทรกเป็น Over-grid image ตามสคริปต์นี้** | รูปถูกเก็บในชีตโดยตรง ไม่ต้องแชร์ไฟล์เป็นสาธารณะ และสคริปต์สามารถลบรูปเก่าที่เกาะเซลล์เดียวกันก่อนวางรูปใหม่ได้ รูปจะเป็นวัตถุเหนือเซลล์ ไม่ใช่ค่าภายในเซลล์ | ไม่มีค่าใช้จ่ายเพิ่มเติมนอกเหนือจาก Google Drive/Sheets ที่ใช้อยู่ | ปานกลาง |
| ใช้สูตร `=IMAGE(URL)` | รูปอยู่ในเซลล์และปรับตามเซลล์ได้ง่าย แต่ URL ต้องเข้าถึงได้จาก Sheets และมักต้องจัดการสิทธิ์การแชร์ไฟล์หรือ URL เพิ่มเติม | ไม่มีค่าใช้จ่ายเพิ่มเติม แต่มีความเสี่ยงด้านการเปิดเผยไฟล์ | ต่ำ |

สำหรับเทมเพลต Photo Report ที่ต้องการควบคุมตำแหน่งรูปและไม่ต้องเปิดไฟล์เป็นสาธารณะ สคริปต์นี้เลือกวิธีแรก โดยใช้ `insertImage(blob, column, row)` และตั้ง anchor cell กับขนาดภาพตามพื้นที่ของเซลล์ [2]. การอ่านโฟลเดอร์ด้วย ID และสร้างไฟล์ด้วย Blob ใช้บริการ DriveApp ของ Apps Script [3].

## ข้อควรทราบ

สคริปต์จะบันทึกรูปใหม่ลงในโฟลเดอร์ที่กำหนดทุกครั้งที่อัปโหลด และจะแทนที่เฉพาะรูปที่วางทับอยู่ที่ anchor cell เดียวกันในชีตเท่านั้น ไฟล์รูปเดิมใน Drive จะไม่ถูกลบ เพื่อป้องกันการสูญหายของข้อมูลและเพื่อให้มีประวัติไฟล์เก็บไว้ตรวจสอบภายหลัง

ผู้ใช้ที่กดใช้งานต้องมีสิทธิ์แก้ไข Spreadsheet และมีสิทธิ์เขียนในโฟลเดอร์ Drive หากพบข้อผิดพลาดว่าไม่พบโฟลเดอร์หรือไม่มีสิทธิ์ ให้ตรวจสอบว่าบัญชี Google ที่ใช้เปิดชีตสามารถเปิด Folder ID ที่ระบุได้
